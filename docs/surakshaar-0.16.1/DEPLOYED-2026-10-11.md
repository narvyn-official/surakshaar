## Implemented

- TinyFish Search on selected manufacturer hosts, public make/model consent notice, bounded results, workspace/account-private history, one-hour cache, safe retry feedback and operator source proposals.
- Source-to-scenario/step links for instructions, AR/3D details and practice questions. New live snapshots reopen impact review. Source/curriculum revisions and concurrent decisions are checked. Human review never edits the authored curriculum or issues certificates.
- A packaged, dependency-complete Fetch worker under systemd, using the same private SQLite database and environment as the web service. Existing hourly maintenance also removes search history older than 30 days.
- Shared Search/Fetch concurrency and budget limits. Deployed configuration: one concurrent request, five reservations per UTC day, one Fetch attempt, no Search retries, recurring checks off. Estimated cost remains zero in the local ledger; this is not a guarantee about provider account-wide billing. No credits or subscription were purchased.
