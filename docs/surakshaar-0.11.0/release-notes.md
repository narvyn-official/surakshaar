# SurakshaAr 0.11.0-dev development pilot

Published 5 October 2026 as `v0.11.0-pilot`. Android 10+, application ID `com.narvyn.suraksha`, version code 24. **Debug-signed development prerelease; not release ready.**

Home / Training / Progress connects the learning journey. Read-only decision replay, older attempt history, a conservative skill passport and separate formative practice preserve original assessment evidence. Fifteen draft cue scenarios cover normal, abnormal and uncertain situations in five domains. Eighty-one offline questions include context, sources and explicit draft/language status. The bounded backend tutor supports product references and refuses unapproved safety content; no live AI provider is provisioned.

Local verification: 165 Android JVM tests, 116 emulator test executions, 38 web unit tests, build/type/lint checks, local authentication/MFA/recovery, tenant isolation, independent review/credential checks and a two-build debug upgrade fixture passed. The same tested APK is published without rebuilding it. Emulator startup first-frame p95 was 826 ms over 30 samples; this is not physical usability or AR performance proof.

Remaining gates: current physical fire/gas AR and representative devices; competent safety/site-procedure and Hindi/Santali review; approved safety retrieval/explain-back AI; production signing/configuration, deployed backup/restore and operational privacy/retention ownership. Earlier software-rendered emulator fire gesture failures are documented. No accreditation, workplace competence or permission to work is implied.

Offline practice is available after installing the APK. Public account hosting is pending; account-linked enrolment, sync and review require a configured server. An in-place update must use the same installation signing identity; do not uninstall or clear data as an upgrade step.
