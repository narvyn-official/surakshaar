# Try the spatial upgrade

## Web

Open `/studio`, choose **Explore**, and select Equipment, Human body, Gas detector, Machinery isolation station, Protective equipment or Emergency response station. Choose **Inspect a part**, then **Close-up**. Rotate, zoom or reset with the named controls. Fire, machinery and PPE also have specimen/state selectors.

Use **Rehearse the complete procedure** for the five industrial sequences. Choose an action, read its feedback and Continue. Reloading preserves this browser’s checkpoint. **Start again** replaces only that rehearsal checkpoint; it does not issue a certificate.

Under **Learn**, start a guided scenario. Every current step has a corresponding spatial scene. First-aid scenes offer individual teaching-part close-ups and a full-body overview. When an anatomy observation is required, explore that structure and explicitly confirm it; inspecting a model alone does not submit an answer.

**Place in AR** becomes available only on a compatible secure-context WebXR browser. Confirm the clear-space notice, scan a horizontal surface, and tap when the placement ring appears. Web scenes are half-scale. Use **Exit AR** for magnified inspection or to change the lesson step. Unsupported devices retain 3D and written learning.

## Android

Install the signed `surakshaar-0.16.0-rc.1-release.apk`. Updates from earlier APKs signed with the same release key preserve local app data. A differently signed older development APK cannot be updated in place; export needed records before choosing any separate migration/uninstall workflow.

Choose Explore for equipment and anatomy, or enter a current lesson and open its step’s spatial view. **Parts** in the equipment explorer opens named construction details. **Inspect** in a lesson’s body scene includes teaching-part close-ups. The existing native room missions, component practice, ordered procedures and first-aid bay remain available.

Camera AR uses a supported Android device with compatible AR Services and permission. Use a clear practice area; placement does not identify real hazards. The emulator checks in this release are not proof of real-phone tracking.

## Content boundary

This is a release candidate for learning and evaluation. Illustrations are generic; use the actual manufacturer’s instructions for real equipment. Safety content and translations still need qualified review, and physical skills require supervised practice.
